Метки в тексте:
- **[локально]** — проверено командой на этой машине, вывод приведён.
- **[источник]** — взято из документации или issue, ссылка рядом.
- **[вывод]** — заключение агента, не проверено.

## Кратко

1. Лучший вариант — **Markdown как единственный источник** отчёта (`report.md`), строгий поднабор
   под 7 разделов skill `report`. HTML для браузера строит из него `report.py`. Один источник, два вида.
2. Схемы в терминале — **готовый текст из box-drawing символов** в блоке ```` ```text ````.
   Его делает агент через `mermaid-ascii` или `beautiful-mermaid` при записи отчёта. Кириллица
   у обоих работает **[локально]**. reviewr показывает такой блок без доработок уже сейчас.
3. `d2` с выводом `.txt` ломает кириллицу (буквы через пробел) **[локально]**. Для русских подписей не годится.
4. Картинки по протоколу Kitty через Herdr 0.9.3 технически проходят: Herdr сам рисует их в Ghostty
   **[локально + источник]**. Но открыто 10+ ошибок отображения. Для отчётов это второй этап и
   отдельное решение владельца, потому что раньше он отказался от «HTML картинкой».

### 1.2. Рендер Markdown в reviewr (`src/markdown.rs`, pulldown-cmark 0.13) [локально]

| Элемент | Поддержка | Как выглядит |
|---|---|---|
| Заголовки | да | без `#`, цвет и жирность уровня из темы |
| Таблицы GFM | да (`ENABLE_TABLES`) | столбцы через ` │ `, линия `─` под шапкой; узкая панель сжимает столбцы до 8 символов, а если и так не влезает — показывает исходный текст таблицы |
| Списки | да | `• ` и `1. `, вложенность отступом |
| Task list | да | `☐` / `☑` |
| Цитата | да | префикс `▎ ` |
| Горизонтальная линия | да | `─` на всю ширину |
| Код ```` ``` ```` | да | подсветка syntect, отступ 2 символа, **перенос по символам** при нехватке ширины |
| ```` ```mermaid ```` | **нет** | одна строка-заглушка `⧉ mermaid graph` (`emit_mermaid_placeholder`) |
| Картинки | нет | `⧉ alt-текст` со ссылкой; `P1/P2/P3` в alt дают цветной значок |
| `<details><summary>` | да | раскрываемый блок `▸`/`▾` |
| HTML-комментарии | скрыты | текст в `<!-- -->` не рисуется |
| `<br>`, `<h1..6>`, `<img>` | да | остальной HTML — только текст |
| GFM alerts `> [!NOTE]` | нет | обычная цитата с текстом `[!NOTE]` |
| Сноски, математика | нет | молчат |

Важно для схем: блок кода шире панели **переносится по символам**, и рамки рассыпаются. Значит,
схема обязана помещаться в ширину панели.

## 5. Рекомендация

### 5.1. Формат

1. Источник отчёта — `report.md` рядом с местом нынешнего HTML. Поднабор: заголовки разделов
   `## 01 Итог` … `## 07 Что дальше`, списки, таблицы, ```` ```text ````, `<details>`, ссылки.
2. `report.py new` создаёт заготовку `.md`. `report.py finish` проверяет разделы и строит
   `.html` в общем стиле рядом. Браузер и agent-desk читают HTML, reviewr читает `.md`.
3. Схема — блок ```` ```text ```` с готовым box-drawing. Над ним исходник mermaid в HTML-комментарии:
   reviewr комментарии не рисует, а `report.py` и агент могут перерисовать схему.

   ```text
   <!-- mermaid
   graph TD
     A[Агент пишет report.md] --> B{Где читать?}
   -->
   ```text
   ┌─────────────────────────┐
   ...
   ```
   ```

4. Генератор схем для агента: `mermaid-ascii -p 0 -x 2 -y 1 --max-width 72` для flowchart,
   `beautiful-mermaid` для sequence. Мелкие схемы и «было/стало» агент рисует руками.

### 5.2. Пределы ширины

- Панель reviewr занимает половину экрана; во вкладке «Сессия» просмотр делит место со списком.
  `herdr pane list` даёт 68 строк, ширину не сообщает. **[вывод]** Бюджет текста — 70–100 столбцов.
- Схема: **не шире 72 столбцов**, направление `TD`, подписи узлов до 25 символов, 3–6 узлов.
  Шире — reviewr перенесёт блок по символам, и рамка развалится.
- Таблица: 2–3 столбца. Широкую reviewr сожмёт, но на 4+ столбцах может показать исходник.
- `finish` может проверять ширину строк в блоках ```` ```text ```` (≤ 72) **[вывод]**.

### 5.3. Работа в reviewr (по шагам)

| Шаг | Что | Цена |
|---|---|---|
| 0 | Ничего: `report.md` с ```` ```text ```` уже читается во вкладке Changes/All files | 0 |
| 1 | Вкладка «Сессия» (решение 3 в `docs/own/decisions.md`) открывает `.reports/**/*.md` | в плане вкладки |
| 2 | Заменить заглушку `⧉ mermaid` на текстовый рендер mermaid: Rust-крейт (`merman`/`meraid` — сначала проверить) или свой порт алгоритма mermaid-ascii | средняя |
| 3 | GFM alerts (`Options::ENABLE_GFM`) для «Нужно от владельца» | малая |
| 4 | Картинки через Kitty (`ratatui-image`) | только после решения владельца и исправления issue Herdr |

### 5.4. Пример раздела: источник и вид в reviewr

Источник `report.md`:

````markdown

| Было | Стало |
|---|---|
| Отчёт — только HTML | Источник — `report.md` |

<!-- mermaid

  A[Агент пишет report.md] --> B[reviewr: вкладка Сессия]
  A --> C[report.py finish: HTML]
