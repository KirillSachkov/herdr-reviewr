# Решения: свой reviewr

Журнал решений владельца по своему инструменту на основе herdr-reviewr.
Каноническая задача: [workspace#20](https://github.com/KirillSachkov/workspace/issues/20)
(инициатива agent-desk). Решения agent-desk, на которые опирается проект: `~/Work/Tools/agent-desk/docs/decisions.md`,
пункты 35–146 (особенно 45, 48, 57, 59, 129, 139–144, 146).

Здесь записаны только ответы владельца. Предложения агента помечены отдельно и решениями не считаются.

## 2026-10-06

1. Форк — публичный GitHub-форк [KirillSachkov/herdr-reviewr](https://github.com/KirillSachkov/herdr-reviewr).
   Remote `origin` — форк, `upstream` — persiyanov/herdr-reviewr (push в `upstream` отключён).
   Агент создал форк 2026-10-06 по этому ответу. Следствие: всё в репозитории, включая этот журнал, публично.
2. Своя сборка ставится рядом с текущим reviewr через `herdr plugin link` под своим plugin id.
   Текущий `persiyanov.reviewr` на `Ctrl+B D` не меняется, пока владелец не решит переключиться.
   Клавишу для своей версии добавляет сессия `workspace` или владелец.
3. Сводка сессии, артефакты и отчёты живут в новой вкладке `4 Сессия`: сверху строка «Нужно от вас»,
   слева список (сводка первой, затем отчёт и артефакты), справа просмотр. Ревью кода остаётся во
   вкладке Changes; у неё появляется режим изменений сессии.
Источник пунктов 1–3: ответы владельца в раунде 1.
4. AI-сводка сессии строится по клавише во вкладке «Сессия» и берётся из кэша agent-desk.
   Панель сама её не запускает. Строка «Нужно от вас» без AI видна всегда.
Источник пункта 4: ответ владельца в раунде 2.

5. У ревью несколько режимов с переключением. Стандартные режимы Git (`u` `b` `t` `g`) остаются.
   Новый режим «Сессия» показывает все изменения этой сессии и не зависит от устройства репозитория:
   все файлы, которые изменил агент, включая файлы вне репозитория (отдельной группой с полным путём).
   Источник — запись разговора; в своём worktree режим добавляет изменения из Git (правки через shell).
6. reviewr показывает сессию той вкладки Herdr, в которой владелец его открыл: агента в той же вкладке.
   Владелец переходит между сессиями навигацией Herdr. Проверено агентом: `herdr agent list` отдаёт
   для агента `tab_id` и `agent_session` (id сессии Claude или Codex).
Источник пунктов 5–6: ответы владельца в раунде 3.
7. Клавиши: `4` — вкладка «Сессия»; `a` — режим «Сессия» в Changes; `A` — построить AI-сводку;
   `o` — открыть выбранный артефакт в браузере или системном приложении; `m` — Markdown текстом
   или исходником (как в upstream). После пробы клавиши можно поменять.
Источник пункта 7: ответ владельца в раунде 4.


8. Доставка комментариев: `s` вставляет их в поле ввода агента, как в upstream; владелец дописывает
   и нажимает Enter. `S` сразу отправляет их сообщением через `herdr agent prompt`. Проверено агентом:
   если агент в состоянии blocked (ждёт ответа на вопрос), Herdr отклоняет отправку; комментарии
   тогда остаются в reviewr.
9. Комментарии уходят агенту той же вкладки Herdr без вопросов. Выбор из списка появляется, только
   если во вкладке нет агента или их несколько.
10. Владелец хочет по клавише видеть все свои комментарии. Это уже есть в upstream: `l` открывает
    список всех комментариев. Конкретного сбоя отправки владелец не назвал; агент проверит отправку
    на пробе.
Источник пунктов 8–10: ответы владельца в раунде 5.

11. Артефакты отбираются механизмом A «файлы сессии по ярусам с причиной»
    ([исследование](research/artifacts.md), раздел 4). В список идут все файлы, которые записала
    сессия: запись разговора (включая subagent) и Git своего worktree. Ярусы: 0 отчёт и сводка;
    1 объявлен агентом (`Artifact`, `open_in_codex`, строка «Артефакт: <путь> — <зачем>»);
    2 план или спека (`ExitPlanMode`, Codex `Plan`, известные папки); 3 новый документ;
    4 упомянут в ответе; 5 изменённый документ; 6 код и конфигурация (свёрнутая группа).
    У каждого файла видна причина. Отметки агента необязательны и только поднимают файл.
    Модель для порядка можно добавить позже по клавише.
12. Отчёт пока пишется в Markdown: хорошо оформленный и со всеми возможностями, которые reviewr
    умеет показывать. Формат отчёта задаёт skill `report` из `workspace`; агент заводит там Issue.
13. Схемы в терминале — текстом с рамками. Жёсткого предела ширины нет: широкая схема не должна
    разваливаться в reviewr. Позже reviewr сам рисует блоки mermaid текстом.
Источник пунктов 11–13: ответы владельца в раунде 6.
14. `Ctrl+B D` полностью переходит на свою сборку `kirill.reviewr`; `persiyanov.reviewr` выключен
    (`herdr plugin disable`). Это меняет решение 2. Агент сразу исправляет найденные проблемы в
    ядре agent-desk. Конфиг Herdr поменян по прямой просьбе владельца: commit `0436155` в `workspace`.
Источник пункта 14: сообщение владельца после пробы шага 2.
15. Вкладка «Сессия» первая и открывается при запуске внутри Herdr; клавиши `1` Сессия, `2` Changes,
    `3` Files, `4` PR (в `herdr/reviewr.toml` workspace). Группы списка: «Отчёт», «Артефакты»,
    «Прочее», «Ссылки из ответа», «Код» — вместо ярусов «Новые документы», «Упомянуты в ответе» и т. п.
    Это уточняет вид решения 11; правила отбора те же. Имена в дереве файлов сокращаются в середине.
16. Пути в ответах и документах открываются в reviewr: ссылка на локальный файл (клик или `Enter`)
    открывает его во вкладке Files, файл вне репозитория — в «Сессии» под «Ссылки из ответа». Как
    открывать путь прямо из панели агента — открытый вопрос (исследование `research/herdr-placement.md`).
Источник пунктов 15–16: сообщение владельца с двумя снимками экрана после пробы.
17. Toggle (`Ctrl+B D`) возвращает на экран панель reviewr, скрытую сменой фокуса в zoomed-вкладке
    (буква «Z»), и закрывает только видимую. Раньше он закрывал скрытую панель, и неотправленные
    комментарии терялись. Решение агента по рекомендации исследования (вариант a); placement остаётся
    `overlay` до ответа владельца.
Источник пункта 17: жалоба владельца на пропадающее окно; механизм — `research/herdr-placement.md`.
18. Окно reviewr остаётся `overlay` на всю область вкладки; шире — владелец сворачивает sidebar своей
    клавишей `prefix+b`. Ни один placement Herdr sidebar не закрывает (проверено исследованием).
19. Путь из панели агента открывается в reviewr обоими способами: Ctrl+клик по ссылке `file://`
    (Claude Code выводит ссылки с `FORCE_HYPERLINK=1` в `~/.claude/settings.json`; link handler
    plugin `kirill.reviewr`) и выделение пути + `Ctrl+B Shift+D` (любой агент). Путь доставляется в
    уже открытый reviewr вставкой с меткой; комментарии не теряются.
Источник пунктов 18–19: ответы владельца в раунде 7.
20. В строке вкладок «Сессии» — проект, ветка и агент; имя проекта также в заголовке панели
    («reviewr · проект»). «Нужно от вас» показывается только в сводке. Отчёт этой работы пишется в
    Markdown уже сейчас (`report.py finish` принимает `.md`), до перевода skill по workspace#30.
Источник пункта 20: сообщение владельца со снимком вкладки «Сессия».
21. Сводка строится видимой клавишей `i` (подсказка «i сводка» в нижней строке; `A` остаётся).
    Пока она строится, строка в списке, строка вкладок («⟳ сводка строится N с»), выноска в сводке и
    индикатор ⟳ это показывают; готовая сводка показывает время построения.
22. Клавиши не зависят от раскладки: русская буква означает латинскую на той же клавише (ЙЦУКЕН →
    QWERTY), в тексте комментария и поиска буквы остаются буквами.
Источник пунктов 21–22: сообщения владельца после вопроса о сводке.
23. Вид markdown: строки «Ключ: значение» подряд (шапка отчёта) остаются строками; под `h1` и `h2`
    линия, как на GitHub; адрес ссылки не печатается после текста, его называет заголовок панели для
    строки под курсором (`⏎ адрес`), клик и `Enter` открывают ссылку как раньше. Номер строки кода —
    его собственный, не номер ограды ```` ``` ````. Выноски по-русски («❗ Важно»).
24. Внутри Herdr подписи по-русски: вкладки «Изменения» и «Файлы», нижняя строка, заголовки панелей.
    Вне Herdr подписи upstream. В строке вкладок состояние агента — цветная точка и слово
    («● … · свободен», «работает», «ждёт тебя»).
25. Картинки: локальные png, jpeg, svg из `![](путь)` и блоки mermaid рисуются картинкой через
    протокол kitty (Herdr рисует его сам). Mermaid рисует `mermaid-rs-renderer` без Node и Chrome.
    Без протокола остаётся текстовая заглушка. Самая высокая картинка — 60 строк.
26. Черновик во временном каталоге не попадает в артефакты, если в проекте есть файл с тем же
    именем или первой строкой (agent-desk `pick::collect`).
27. Сводка, построенная при скрытой панели, присылает уведомление Herdr «Сводка готова». Кадр
    рисуется одним synchronized update (DEC 2026), Herdr не показывает рваный кадр.
28. Не делаем: ссылки OSC 8 (клик и `Enter` уже открывают ссылку в reviewr, Ctrl+клик Herdr не
    добавит пользы); флаг раскладки kitty (Herdr не передаёт клавишу базовой раскладки, нужна своя
    таблица из решения 22); прогресс OSC 9;4 и уведомления OSC 9 (Herdr их поглощает); цвет
    подчёркивания SGR 58 (Herdr его теряет); крупный шрифт заголовков (ячейка Herdr хранит только цвет, стиль и ссылку).
Источник пунктов 23–28: ответ владельца «давай всё это исправим и улучшим» на оценку вида;
возможности Herdr проверены по исходникам v0.9.3.
